# 디자인 적용 계획

## 방향
전체 페이지를 한 번에 갈아엎기보다, 기존 레이아웃과 구조는 유지하면서 컬러, 테두리, 강조 방식만 통일하는 방향으로 진행합니다.

- 기존의 강한 초록 포인트 컬러를 줄이고 중성 톤 중심으로 정리
- 흰 배경 + 은은한 그림자 + 그라데이션 테두리 조합으로 통일감 확보
- 정말 중요한 CTA만 강조하고, 나머지는 차분한 정보 계층으로 정리

<br>

## 핵심 원칙
디자인 전체에 아래 원칙을 공통 적용합니다.

- 기본 배경은 `#FFFFFF`, 필요 시 페이지 바탕은 `gray-50` 계열 사용
- 기본 텍스트는 `#111111`, 보조 텍스트는 `#6B7280` 수준의 중성 회색 사용
- 기본 아이콘은 `#333333` 계열로 통일
- 카드와 버튼은 단색 민트 채우기 대신 `white + gradient border` 중심으로 변경
- 초록 포인트는 선택 상태, 성공 상태, 핵심 CTA 등 꼭 필요한 곳에만 제한적으로 유지

공통 그라데이션 테두리는 아래 값을 기준으로 사용합니다.

```css
background-image: linear-gradient(#FFFFFF, #FFFFFF), linear-gradient(135deg, rgba(226, 218, 255, 0.76), rgba(196, 247, 224, 0.74), rgba(202, 230, 255, 0.76));
background-origin: border-box;
background-clip: padding-box, border-box;
```

<br>

## 적용 순서
리스크를 줄이기 위해 공통 스타일을 먼저 정리한 뒤, 화면 단위로 확장합니다.

1. 공통 토큰 및 스타일 유틸 정리
- 그라데이션 테두리용 공통 클래스 또는 유틸 스타일 정의
- 텍스트, 아이콘, 보더에 사용할 중성 컬러 기준 정리
- 인라인으로 흩어진 컬러 사용을 줄이고 재사용 구조 마련

2. 공통 컴포넌트 우선 수정
- `AppShell` 헤더 버튼
- 공통 버튼
- 공통 카드
- 필터 칩 / 상태 칩
- 모달 / 다이얼로그

3. 주요 페이지 순차 적용
- 홈
- 공연 목록 / 공연 상세
- 2차 거래소 / 재판매
- 지갑 / 거래 내역
- 내 티켓 / 컬렉션
- 마이페이지 / 설정

4. 최종 점검
- 활성 상태와 비활성 상태 구분이 충분한지 확인
- 모바일 화면에서 대비와 가독성 확인
- 잔여 초록 포인트 컬러 제거 여부 확인

<br>

## 페이지별 적용 방식

## 홈
홈은 카드 중심 구조를 유지하되, 포인트 컬러 사용량을 줄이고 카드 간 통일감을 강화합니다.

- 카드 border 제거 후 흰 카드 + 은은한 그림자 유지
- 랭킹 배지는 금/은/동 메달 컬러를 유지하고 그 외 요소는 중성 톤으로 정리
- 배너, 카드 내부 텍스트, 부가 정보의 명도 차를 조절해 위계 정리

<br>

## 공연 목록 / 공연 상세
콘텐츠 탐색성은 유지하면서 필터와 정보 블록을 더 정돈된 방식으로 통일합니다.

- 비활성 필터 칩은 투명 배경 + 연한 보더
- 활성 필터 칩만 채운 스타일 유지
- 정보 카드와 박스는 흰색 배경 + 그라데이션 보더 또는 연한 중성 보더 적용
- 제목은 진하게, 날짜/장소는 중간 회색으로 위계 강화

<br>

## 2차 거래소 / 재판매
거래 관련 화면은 정보 밀도가 높기 때문에 강조를 줄이되 중요 액션은 유지합니다.

- 재판매 카드, 가격 박스, 요약 영역에 같은 보더 시스템 적용
- 메인 CTA만 상대적으로 강하게 두고 보조 버튼은 화이트 베이스로 정리
- 설명용 박스는 과한 초록 대신 연한 중성 배경이나 그라데이션 보더로 조정

<br>

## 지갑 / 거래 내역
수치 정보와 거래 이력을 더 차분하게 읽히도록 조정합니다.

- 잔액 카드와 거래 요약 카드에 그라데이션 보더 적용
- 금액 강조는 초록 대신 검정/다크그레이 중심으로 조정
- 성공/증가 같은 특수 상태에만 제한적으로 의미 색 유지

<br>

## 내 티켓 / 컬렉션
핵심 콘텐츠인 티켓이 가장 돋보이도록 주변 UI를 덜 튀게 정리합니다.

- 티켓 리스트 카드와 필터칩의 보더, 배경, 텍스트 위계를 통일
- 컬렉션은 기존 오라/글로우 비주얼은 유지하고 주변 UI만 차분하게 조정
- 배지와 상태 정보는 의미 전달이 유지되는 선에서 채도 축소

<br>

## 마이페이지 / 설정
현재 일부 적용한 방향을 기준 스타일로 삼아 전체 통일감을 만드는 영역입니다.

- 프로필 링, 설정 버튼, 정보 카드, 메인 CTA를 같은 그라데이션 보더 스타일로 정리
- 아이콘과 강조 텍스트는 `#333333` 또는 `#111111` 계열로 통일
- 기존 민트 단색 영역은 화이트 베이스 중심으로 교체

<br>

## 공통 컴포넌트 전략
전체 화면에 반복 적용할 수 있도록 공통 스타일 단위를 먼저 마련합니다.

- `gradient-outline-card`
- `gradient-outline-button`
- `neutral-icon-button`

이렇게 정리하면 각 페이지에 같은 시각 언어를 빠르게 확장할 수 있고, 화면별 톤 차이도 줄일 수 있습니다.

<br>

## 주의사항
모든 영역에 동일한 강조를 주면 오히려 밋밋해질 수 있으므로, 정보 계층은 반드시 유지해야 합니다.

- 모든 버튼을 그라데이션 보더로 바꾸지 않기
- 선택 상태와 비선택 상태 차이는 반드시 유지하기
- 상태 배지는 의미 색을 완전히 제거하지 말고 필요한 만큼만 남기기
- 컬렉션처럼 원래 비주얼이 강한 화면은 메인 오브젝트보다 주변 UI만 조정하기

<br>

## 추천 실행안
가장 안전한 작업 흐름은 아래와 같습니다.

1. 공통 그라데이션 보더 스타일 유틸 작성
2. 버튼 / 카드 / 헤더 아이콘 공통 컴포넌트 반영
3. 마이페이지 기준으로 스타일 확정
4. 홈, 공연 목록, 내 티켓 순으로 확장
5. 마지막에 거래소, 지갑, 컬렉션 화면 미세 조정
