# 디자인 롤아웃 작업 체크리스트

## 상태 표시
- `[ ]` : 아직 시작 전
- `[~]` : 진행 중
- `[x]` : 작업 완료

현재는 기존 구조를 유지하면서, 쨍한 초록 포인트를 줄이고 `화이트 배경 + 그라데이션 보더 + 중성 텍스트` 기준으로 공통 톤을 맞추는 방향으로 정리 중입니다.

<br>

## 1. 공통 스타일 기반
- [x] 공통 그라데이션 보더 유틸 클래스 추가
- [x] 공통 버튼 스타일 정리
- [x] 공통 아이콘 버튼 스타일 정리
- [x] 공통 카드/서피스 스타일 정리
- [~] 잔여 인라인 색상/예외 케이스 정리

<br>

## 2. 공통 컴포넌트 반영

- [x] 튜토리얼 모달/칩/CTA 톤 정리
- [~] 공통 입력창/상태 뱃지 정리
- [ ] 공통 폼/모달 세부 패턴 추가 정리
