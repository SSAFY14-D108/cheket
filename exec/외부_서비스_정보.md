# CHEKET 외부 서비스 정보

## 개요

본 문서는 CHEKET 프로젝트에서 사용하는 외부 서비스 정보를 정리합니다.
공연 추천, 푸시 알림, 이미지 저장, 캐시 및 대기열 관리 등을 위해 필요한 정보를 포함합니다.

## 1. AI 서비스

### 1.1 FastAPI AI Server

- **서비스 용도**: 사용자 관심 데이터(찜한 공연, 예매한 공연, 최근 검색어)를 기반으로 공연 추천 결과 생성
- **연동 방식**: Spring Boot → FastAPI HTTP 호출
- **통신 방식**: `application/json` 기반 REST API
- **연관 클래스**:
  - `RecommendationAiClient.java`
  - `RecommendationRequestPayload.java`
  - `RecommendationResponsePayload.java`
- **동작 방식**:
  1. Spring Boot 서버에서 사용자 찜 목록, 예매 목록, 최근 검색어, 추천 후보 공연 목록을 수집
  2. 이를 AI 서버에 HTTP 요청으로 전달
  3. AI 서버에서 임베딩 API 호출을 통해 코사인 유사도 연산 후 추천 공연 목록 반환
  4. AI 서버 호출 실패 시, 서버 내부 fallback 추천 로직으로 대체

## 2. 데이터베이스 서비스

### 2.1 MySQL

- **서비스 용도**: 메인 데이터베이스
- **연결 정보**:
  - 데이터베이스: `cheket`

### 2.2 Redis

- **서비스 용도**: 캐시 및 실시간 상태 데이터 관리
- **주요 사용 목적**:
  - JWT 블랙리스트/토큰 관리
  - 티켓팅 대기열 관리 (ZSET 기반 순번 관리)
  - 입장 가능 사용자 상태 관리 (TTL 기반 만료 처리)
  - 대기열 토큰 메타데이터 저장 (Hash 구조)
- **주요 특징**:
  - 빠른 읽기/쓰기 성능을 활용해 실시간 트래픽 상황 대응
  - TTL 기반 만료 처리 가능

## 3. 푸시 알림 서비스

### 3.1 Firebase Cloud Messaging (FCM)

- **서비스 용도**: 사용자 모바일 기기에 푸시 알림 전송
- **연동 방식**: Spring Boot → Firebase Admin SDK → FCM
- **주요 알림**:
  - 공연 시작 알림
  - 정산 완료 알림
  - 공연 등록/수정 요청 알림
  - 2차 거래 완료 알림
- **동작 방식**:
  1. 서버에서 알림 생성
  2. 알림 내용을 DB에 저장
  3. 사용자 디바이스의 FCM 토큰을 통해 푸시 발송
- **연관 구성 요소**:
  - `FirebaseConfig`
  - `PushNotificationService`
  - `NotificationService`
- **비고**:
  - 사용자별 FCM 토큰을 저장하여 특정 사용자에게 개별 알림 발송
  - DB 저장과 푸시 발송을 함께 처리하여 앱 내 알림 내역과 실시간 푸시를 동시에 지원

## 4. 인증/메시징 서비스

### 4.1 Solapi (SMS 문자 인증)

- **서비스 용도**: 사용자 휴대폰 번호 인증
- **연동 방식**: Spring Boot → Solapi REST API 호출
- **주요 기능**:
  - 인증번호 SMS 발송
  - 사용자 입력 인증번호 검증
- **사용 시점**:
  - 회원가입 시 본인 인증
  - 계정 보안 강화
- **비고**:
  - 외부 SMS API를 활용하여 실제 사용자에게 문자 전송
  - 인증번호는 서버에서 생성 및 검증

## 5. 객체 스토리지

### 5.1 AWS S3

- **서비스 용도**: 공연 포스터 이미지 및 상세 소개 이미지 저장
- **연동 방식**: Spring Boot → AWS S3 업로드
- **저장 대상**:
  - 공연 포스터 이미지
  - 공연 상세 설명 이미지
- **리전**: `ap-northeast-2`
- **버킷**: `cheket-images`

## 6. 블록체인 서비스

### 6.1 Blockscout (블록체인 탐색기)

- **서비스 용도**:
  - 블록체인 트랜잭션 및 상태 조회
  - NFT 티켓 발행 및 거래 내역 확인

- **연동 방식**:
  - 블록체인 네트워크와 연결된 Explorer(Web UI) 활용

- **주요 활용 내용**:
  - 티켓 NFT 발행(Mint) 결과 확인
  - 트랜잭션 성공/실패 여부 검증
  - 블록 및 거래 내역 조회

- **비고**:
  - 블록체인 상의 데이터를 직접 조회하기 어려운 문제를 해결하기 위해 Explorer 도구 활용
  - 운영 및 디버깅 과정에서 트랜잭션 상태를 확인하는 용도로 사용
