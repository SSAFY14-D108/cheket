> 로컬 실행 (권장 순서)

```bash
# 1) DB/Redis 기동
docker compose -f docker-compose.local.yml up -d

# 2) Backend 실행
cd backend
./gradlew bootRun
```

> Docker 배포형 실행

```bash
docker compose up -d backend mysql redis
```

> 확인 명령어

```bash
java -version
cd backend && ./gradlew --version
curl -i http://127.0.0.1:8080/actuator/health
```

## 환경 변수

값(시크릿)은 문서에 쓰지 않고 **키 이름만 관리**합니다.

### Database

- `MYSQL_ROOT_PASSWORD`: MySQL Root 계정 비밀번호
- `MYSQL_DATABASE`: MySQL 데이터베이스
- `MYSQL_USER`: MySQL 유저
- `MYSQL_PASSWORD`: MySQL 유저 비밀번호

### Redis

- `REDIS_PASSWORD`: Redis 비밀번호

### JWT

- `JWT_SECRET`: JWT secret 키
- `JWT_ACCESS_EXPIRATION`: Access Token 만료시간
- `JWT_REFRESH_EXPIRATION`: Refresh Token 만료시간

### Wallet - 지갑 관리

- `KEYSTORE_PASSWORD`: KEYSTORE 접근 비밀번호
- `KEYSTORE_DIR`: KEYSTORE 저장 경로

### SMS (SOLAPI) - sms 인증 관련

- `SOLAPI_API_KEY`: SOLAPI 서비스 요청 겅로
- `SOLAPI_API_SECRET`: SOLAPI 서비스 접근 API secret 키
- `SOLAPI_SENDER_NUMBER`: SOLAPI 서비스 요청 대표번호

### Blockchain

- `BLOCKCHAIN_RPC_URL`: 블록체인 RPC 경로
- `PRIVATE_KEY`: 블록체인 네트워크 private 키
- `BLOCKCHAIN_INITIAL_TRANSFER_AMOUNT`
- `BLOCKCHAIN_SSF_CONTRACT`
- `BLOCKCHAIN_CHAIN_ID`
- `BLOCKCHAIN_STAKEHOLDER_NFT`
- `BLOCKCHAIN_EVENT_NFT`
- `BLOCKCHAIN_TICKET_NFT`
- `BLOCKCHAIN_SETTLEMENT`
- `BLOCKCHAIN_PURCHASE_ROUTER`
- `BLOCKCHAIN_MARKETPLACE`
- `BLOCKCHAIN_ESCROW`

### AWS / S3

- `AWS_ACCESS_KEY`: AWS access 키
- `AWS_SECRET_KEY`: AWS secret 키
- `AWS_REGION`: AWS region
- `AWS_BUCKET`: AWS S3 버킷

### Firebase - 알림 전송

- `FIREBASE_CONFIG_PATH`

### AI

- `AI_SERVER_URL`: AI 서버 요청 경로

### Pinata (IPFS)

- `PINATA_JWT`
- `PINATA_GATEWAY`

### Docker Compose 오버라이드(컨테이너 내부)

- `SPRING_DATASOURCE_URL`: SPRING DB 경로
- `SPRING_DATA_REDIS_HOST`: SPRING Redis Host
- `SPRING_DATA_REDIS_PASSWORD`: SPRING Redis 비밀번호
